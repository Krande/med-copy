subroutine mfiodr ( integer*8  fid,
integer  class,
character*(*)  oname,
character*(*)  desc,
integer  cret 
)

Lit une description associée à l'objet objectname de type med_class dans le fichier fid .

Paramètres
fidIdentificateur du fichier.
classType d'objet de haut niveau MED (champ, maillage, ...) .
onamenom de l'objet a traiter de type medclass.
descDescription, chaîne de caractères de taille maximum MED_COMMENT_SIZE caractères.
cretretour négatif en cas d'erreur (MED_ERR_HOWTO), Zéro sinon.
