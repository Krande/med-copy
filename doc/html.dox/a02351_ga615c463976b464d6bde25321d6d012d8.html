med_err MEDfileObjectDescriptionWrByPath ( const med_idt  fid,
med_path *const  medpath,
const char *const  description 
)

Ecrit une description associée à l'objet accessible par le chemin med_path dans le fichier fid .

Paramètres
fidIdentificateur du fichier.
medpathidentifie un objet med par l'intermédiaire d'une succession de medpath.nname noms stockés dans medpath.name[].
descriptionDescription, chaîne de caractères de taille maximum MED_COMMENT_SIZE caractères.
Valeurs retournées
med_errretour négatif en cas d'erreur (MED_ERR_HOWTO), Zéro sinon.

Ecrit une description associée à l'objet accessible par le chemin med_path dans le fichier fid .

Remarques
Classes d'objets concernées:
Les classes d'objets MED utilisables sont :
  • MED_MESH
  • MED_FAMILY
  • MED_GROUP
  • MED_FIELD
  • MED_MESH_SUPPORT
  • MED_ELSTRUCT
  • MED_EQUIVALENCE
  • MED_LOCALIZATION
  • MED_PROFILE
  • MED_INTERPOLATION
  • MED_NUMERICAL_DATA
  • MED_JOINT
  • MED_FILE
Utilisation de medpath:
  • medpath.nname indique le nombre de noms composants le chemin d'accès. nname == 1 sauf pour MED_FAMILY_{NODE,ELEM], MED_GROUP et MED_JOINT où nname == 2.
  • medpath.name[medpath.nname]: Indique les noms composants le chemin d'accès. Si nname == 1, name[0] déclare le nom de l'objet concerné. Si nname == 2, name[0] déclare le maillage associée pour l'objet de nom name[1].
